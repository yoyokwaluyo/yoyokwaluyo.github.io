# Portfolio

Daftar proyek portfolio sekarang diambil dari `assets/data/portfolio.json`.

Untuk menambah project baru, tambahkan object baru dengan field utama berikut:

- `id`
- `year`
- `sortOrder` untuk urutan manual
- `title`
- `category`
- `excerpt`
- `image`
- `imageAlt`
- `modalTitle`
- `modalImage`
- `modal.paragraphs`
- `modal.list`
- `links`

Setelah JSON diubah, halaman akan render ulang otomatis saat dibuka lewat server web statis.
